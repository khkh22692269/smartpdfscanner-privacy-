# Smart PDF Scanner — Privacy Policy / سياسة الخصوصية

Public, bilingual privacy policy for the Android app `com.smartpdfscanner`.

The app's actual source code remains in the **separate private** repository `SmartPDFScanner`.

## Publish with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)** and click **Save**.
4. Once the deployment succeeds, check the public page:
   **https://khkh22692269.github.io/smartpdfscanner-privacy-/**
5. Copy that verified HTTPS URL into **Google Play Console → Policy and programs → App content → Privacy policy**.
6. Make the policy available **from inside the app** as well, per Google Play requirements.

> The repository name **ends with a hyphen** (`smartpdfscanner-privacy-`), so the Pages URL must also include that trailing hyphen.
